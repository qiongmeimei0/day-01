# day-01 模型 V2

本版本默认运行模拟交易，不会真实下单。

## 新增功能

- 首次启动下载并缓存 5000 根 BTC/USDT 永续合约 1 小时K线。
- 使用 `TimeSeriesSplit(gap=1)` 做5折时间序列验证。
- 使用买入、卖出、观望三类标签。
- 只有最高类别概率达到60%才产生交易信号。
- 回测扣除开平仓手续费与滑点。
- 输出测试集平衡准确率、总收益率、最大回撤、开仓次数和夏普比率。
- 增加 ATR、布林带位置、EMA趋势、收益率、波动率、成交量变化等特征。
- 训练和交易事件可以发送Gmail通知。

## 安装和启动

```bash
pip install -r requirements.txt
python bot.py
```

首次启动下载和训练可能需要几分钟。历史K线保存在 `data/ohlcv.csv`，模型保存在
`rf_model.pkl`，两者都不会提交到GitHub。

## 安全设置

默认 `.env` 应保持：

```text
LIVE_TRADING=false
EMAIL_ENABLED=false
```

真实API密钥和Gmail应用专用密码只保存在服务器 `.env`，绝对不要上传到公开仓库。

## 重要说明

回测结果不代表未来收益。开启实盘前应长期运行模拟模式，并核对OKX账户模式、合约张数、
手续费、资金费、网络异常和订单成交情况。
